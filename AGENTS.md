# Instruções do projeto

- Após cada alteração solicitada pelo usuário, valide o trabalho, crie um commit e faça push normal para `origin/main`, publicando no GitHub Pages.
- Essa publicação já foi autorizada pelo usuário; não peça nova confirmação a cada atualização.
- Confirme o resultado da publicação sempre que possível e informe qualquer falha de push ou implantação.
- Preserve o histórico de vagas, os identificadores de registros e a compatibilidade de backups. Não publique credenciais ou dados locais privados do navegador.
